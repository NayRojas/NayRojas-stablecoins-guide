# Stablecoins: guía para equipos

Sitio estático con un glosario de 100 términos sobre stablecoins y blockchain (cada uno con su lectura de negocio), una ruta de aprendizaje sugerida, videos de YouTube y cursos en español de Platzi, Udemy y Coursera.

Pensado para equipos técnicos que necesitan entender también el lado de negocio.

## Estructura

- `index.html`: página principal
- `data/glosario.js`: los 100 términos (`t` término, `c` categoría, `d` definición, `n` lectura de negocio)
- `data/recursos.js`: videos y cursos
- `assets/`: estilos y lógica (búsqueda, filtros, índice alfabético)

Para agregar o corregir un término, edita `data/glosario.js`; no hace falta compilar nada.

Material educativo; no constituye asesoría financiera ni legal.
